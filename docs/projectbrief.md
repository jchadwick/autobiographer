# Project Brief

## Overview
The Autobiographer application helps users create comprehensive autobiographies by guiding them through personal questions and recording their responses. It supports both text and voice input, with real-time speech-to-text transcription, and produces a cohesive third-person narrative.

## Project Goals
- Intuitive web application for autobiography creation
- Text and voice response capabilities with real-time transcription
- Secure storage of text and audio
- Transform responses into a third-person narrative
- Flexible, extensible architecture (future mobile support)

## Target Audience
- Individuals preserving personal histories
- Family members documenting stories
- Memoir writers
- Legacy document creators

## Core Features (see productContext.md for details)
- Interactive Question System
- Multimodal Input
- Narrative Generation
- Session Management
- Data Management

## Constraints
- Local speech-to-text (no external APIs)
- User privacy and data security
- Efficient handling of large audio files
- Consistent narrative style

## Success Criteria
- Users complete an autobiography in <10 hours
- 95%+ speech-to-text accuracy (clear speech)
- Positive feedback on narrative and questions
- Responsive performance with large datasets
