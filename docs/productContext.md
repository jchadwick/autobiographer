# Product Context

## Purpose
Autobiographer exists to help people preserve their life stories in a structured, accessible, and engaging way. It addresses the challenge of capturing memories, experiences, and wisdom for personal reflection and for sharing with future generations.

## User Experience Goals
- Guided, stress-free storytelling through curated questions
- Flexible input: text, voice, and editing capabilities
- Progress tracking and session management for long-form projects
- Privacy, security, and user control over data
- Accessible, responsive, and intuitive interface

## Problems Solved
- Overcomes the blank-page problem by providing structured prompts
- Makes autobiography creation accessible to non-writers
- Ensures stories are preserved in a cohesive, organized format
- Supports multimedia (audio/text) and export for sharing/printing

## Feature Context (see feature-requirements/ for details)
- Interactive Question System: Life-stage and thematic prompts, dynamic follow-ups, custom questions
- Multimodal Input: Rich text, voice recording, real-time transcription, editing
- Narrative Generation: Third-person, multiple styles, editable, exportable
- Data Management: Secure, versioned, backup/export, privacy controls
- Offline Capabilities: Work offline, auto-sync, no data loss
- User Management: Account creation, profile, session persistence, GDPR compliance
- UI: Responsive, accessible, progress indicators, theming
