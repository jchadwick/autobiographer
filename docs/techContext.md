# Tech Context

## Frontend
- React.js (UI framework)
- Redux or Context API (state management)
- Material-UI or Chakra UI (UI components)
- React Router (routing)
- Formik/React Hook Form (forms)
- Axios/Fetch (API communication)
- Service Workers, IndexedDB (offline support)

## Backend
- Node.js with Express (server framework)
- Passport.js/JWT (authentication)
- Swagger/OpenAPI (API docs)
- Joi/Yup (validation)
- Winston/Pino (logging)
- RESTful API, optional GraphQL
- WebSocket (real-time)

## Database & Storage
- MongoDB or PostgreSQL (primary DB)
- Redis (caching)
- File storage for audio, exports, backups

## AI & Processing
- OpenAI Whisper or Mozilla DeepSpeech (speech-to-text)
- NLP for narrative generation

## DevOps
- Git, Docker, CI/CD pipeline
- Automated testing (unit, integration, E2E)
- Monitoring, analytics

## Constraints
- Local speech-to-text (no external APIs)
- Encryption, GDPR compliance
- Performance and scalability
